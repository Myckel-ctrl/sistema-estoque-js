# 📦 Gerenciamento de Estoque em JavaScript

Sistema de estoque para terminal, feito em JavaScript com Node.js, para praticar lógica de programação.

## 🚀 Funcionalidades

- Cadastrar, listar e buscar produtos
- Calcular o valor total do estoque
- Remover produto e atualizar preço
- Mostrar o produto mais caro e a quantidade cadastrada

## ✅ Regras

- Nome não pode ser vazio nem duplicado
- Preço deve ser maior que zero
- Quantidade não pode ser negativa

## ⚙️ Como executar

```bash
git clone https://github.com/Myckel-ctrl/sistema-estoque-js.git
cd sistema-estoque-js
index.js
```

## 🧠 Conceitos praticados

Variáveis, condicionais, laços, arrays, objetos, funções e métodos de array (`find`, `forEach`, `reduce`).
